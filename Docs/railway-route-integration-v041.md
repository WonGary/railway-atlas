# 路路通径路与乘车区间 · 0.4.1 (18)

导入的路路通车次现在会带入列车经由线路、站所顺序和里程。沿线旅行在主地图按这些径路匹配铁路几何；护照和三种明信片使用同一套匹配逻辑，先在列车径路上截取乘车起终点，再加载对应区间的地图。

## 数据和匹配

- 公开包中的线路资源按内容标识识别，不依赖混淆后的文件名。已核对的 `hU.dat` 含 796 条线路和 14,997 条径路；2026-11-08 取得的包版本标签为 2026-11-14。版本日不表示所有内容已生效。
- 列车径路以内部列车编号关联车次，并核对首末站、停站顺序及每站累计里程。同名车次存在多个不同且无法区分的径路时保留时刻查询，禁止自动选一路画图。
- 地图匹配读取 OSM / OpenRailwayMap 实际轨道，以线路名、共线区段、线路编号约束图搜索，并校验里程。命名隧道通过相同线路编号归入所属线路；站场只接纳附近的无名通过轨道。
- 先读现有 Z10 地图缓存。缺少坐标时使用 OpenRailwayMap 自身的设施搜索，必要时使用 Overpass；轨道下载使用专门入口等待有线路属性的主源，不让无线路名的概化底图抢先替换。经验功能使用独立缓存，不改变主地图的加载优先级。
- 下载车站与径路持久保存，支持离线再次打开。缓存几何与完整时刻、径路快照共同核对，防止更新后复用不同版本的线路。
- 主地图处于“仅缓存”模式时，体验路线也只读缓存；显式点击离线库同步按钮仍可更新时刻资料。
- 缺图、站名有歧义、断轨或里程明显不符时报告具体区段；不会用站间直线代替铁路。

## 乘车区间

- 从库中选择车次时，将日期时刻和径路快照保存在护照草稿中；保存后随 JSON 备份保留。
- 修改上车站自动采用该站发车时间，跨日车次同时转换为实际上车日期。
- 起终点必须按该车次行进方向出现；反向、同站、缺失站或重复停站有歧义时不绘制。
- 护照的“查看乘车路线”展示截取后的轨道和经停站。红票、蓝票、路线明信片均使用相同区间；不再绘制任选城市路网。
- 编辑期间清除旧路线，尚未匹配完成时禁用图片导出，防止修改了票面而仍导出上一段线路。
- 旧时刻库继续可读；需要径路时可同步升级，原库保留备份。含径路的完整转换 JSON 也可直接导入。

## 验证范围

核心回归覆盖原体验功能、截取后几何保持一致、错误方向、无轨道拒绝、跨日上车、资源截断、坏线路引用、里程不一致及完整库回读。真实库核对 G1、G101、T109、G6580 的全部停站里程。

动态匹配 G6580（2026-11-09）为 217,215 米；深圳北至佛山西为 135,360 米，截取及单独匹配该段得到相同轨道。空缓存联网实测深圳北至光明城约 16,358 米。

这不是所有车次的全国逐趟验收。线路数据与 OSM 的覆盖差异仍可能造成少量车次无法匹配；站场并行股道有近似，按时刻插值的位置不是实时定位。本次交付验证 macOS，iOS 项目源文件及版本同步更新但未运行 iOS 模拟器。
