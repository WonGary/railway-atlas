# 铁道漫游 0.4.0 / build 17

本次按用户 2026-11-08 的四项修正实现，保留主地图、个人护照、旧导入资料及现有设置。

## 城市题库

移除 16 城白名单，使用全国概览全部可用城市，排除“未归档”“氢淞号”等非城市标签。全国覆盖指随附/已缓存数据收录的城市，不代表所有县市或每座城市的完整铁路网。

本次安装版实测为 **72 城**。

“加入世界缓存题库”和“读取缓存”只读现有地图缓存，不自动下载世界地图。对探索目录中有至少两条城市轨道身份的缓存地区生成周边 45 km 内的线形片段，并明确标记为缓存片段。画布仍只接收归一化 x/y；不显示站名、语言、坐标、真实颜色或地图详情。

## 路路通完整公开包的本地读取

来源是路路通官网直接提供的 Android 包：`http://down.lltskb.com/lulutong.apk`。本次版本标记为 **2026-11-14**；调查、集成日期为 **2026-11-08**。未来版本标签不代表所有内容已在当前日期生效。

首轮实际同步得到：

- 15,131 条车次（全部名称索引均有且仅有一条时刻记录）；
- 3,330 个站名；
- 143,685 条停站记录；
- 1,386 条带需要进一步核对的条件开行/状态标记。

这是公开 APK 内的全量时刻部分。没有证据说明它等于路路通应用在线更新后的全部资料，更不等于完整历史运行图库。票价、交路、线路里程资料等未纳入本次时刻查询。

本次查明的是公开客户端的数据载体和读取方式。路路通自身从铁路部门或其他渠道收集、校订数据的上游流程没有得到独立证实，不能据此声称其具有公开官方接口。

读取器通过 HTTP Range 获取 ZIP 中央目录和数据资源，校验 ETag 一致性、响应区间、解压长度及 CRC32；不会执行 APK 或加载其中的 DEX/本地代码。该公开下载地址使用 HTTP；网络例外仅限 `down.lltskb.com`，没有关闭全局 TLS 检查。CRC 校验用于检测损坏，不是供应方数字签名。

格式互操作依据本次公开包内容及独立核对：

- 名称字典长度使用大端整数和 UTF-8；
- 车次/车站索引及里程字段使用 base-255 二字节表示；
- 有效期用四个 base-128 数位表示 YYYYMMDD；
- 每站包含站名索引、到达钟点、停站分钟、累计里程；
- 跨午夜按前站离站时间展开为累计分钟；
- 首站为出发时间，末站仅提供到达时间。

已用此前保留的 2026-11-08 12306 G6580 原响应核对其全部 9 站的到达和离站时间。全库还做了数量、唯一索引、站名范围、有效日期和单调时刻验证。这不是对 15,131 条车次运行事实逐条独立认证。

未把不理解的标记转成“每日开行”。搜索按资料的排图有效期筛选，条件开行、临时停运和实时状态仍提示核对。2099 等远期上限原样保留为资料字段，不承诺实际长期运行。

“同步路路通离线库”是用户主动触发，成功才原子替换并保留前一版。没有第三方登录、后台轮询或个人订单访问。供应方格式变化、数量不齐或损坏会停止替换。数据库保存于本机：

`~/Library/Application Support/RailwayAtlas/Experiences/TimetableLibrary/lulutong.json`

本次已把完整转换库载入该路径，重新打开新版后即可离线搜索。同步按钮默认可见；后续由用户主动更新。

应用源码及安装包不内嵌路路通数据库。未取得供应方对公开分发数据库的许可，也未作此种分发。用户本机加载/更新与应用打包分开处理。

护照、明信片和沿线旅行共用此库；选择时刻会生成待核对草稿，不自动把订单或时刻记录计为已乘坐。

## 主地图沿线旅行

首条完整匹配：2026-11-08 G6580 香港西九龙—肇庆东，全程 9 站、8 个区间，约 217 km。

几何来自既有 OpenStreetMap / OpenRailwayMap 地图缓存，筛选运营中的广深港（3021）、南广（3029）正线及经停站附近高铁站场。转换脚本为 `Scripts/build-experience-route.mjs`，输入可由 `RailwayAtlasCheck --export-experience-cache` 只读导出。

路径在源轨道几何上搜索，不用站点间直线补缺。Z10 几何拼接使用 25 m 容差；经停站吸附到连通正线，本站最大偏差小于 43 m。结果是实际铁路走廊的公开地图表示，不保证具体上下行、站台股道或调度径路。

主地图显示列车、24 小时钟、跨日标记、暂停、倍速、拖动与跟随开关。每个区间按沿轨道累计距离和时刻插值，停车期间坐标不动。Apple MapKit 与无底图缓存/离线画布均支持。退出后恢复原视野。

其他车次只有时刻库并不等于已知径路。尚无匹配几何的日期车次明确提示不能在地图播放，不用直线动画冒充。全库自动径路匹配及视频导出未在本次实现。

## 主地图线路时光机

原历史事件介绍页已改为地区选择和主地图时间轴。随附 OSM 详细快照中具有区段日期的地区可直接播放；也可以只读当前地图范围内带日期的缓存区段。

只采用具体 way 的 `start_date` / `opening_date`；不把整条 relation 的首通日期套到后来延伸段，更不使用 OSM 编辑日期。已开通区段按时间叠加；若有 `construction:start_date`，可显示施工阶段；已知停用日期后隐藏。只有年/月精度的日期，保守到该年/月末才纳入。

没有日期的区段默认隐藏，可作为灰虚线另行打开，但不会计入历史路网。界面显示覆盖与未知数量，以及可追溯的 OSM way 来源。

此功能是“现存轨道几何按有据区段日期回放”，不是完整历史铁路重建：拆除旧线、改线、迁站及缺失日期需要继续补档案。已知局限在功能页保留。

## 验证入口

- `RailwayAtlasCheck --experience-regression`：旧体验回归及新增轨道、日期、路路通格式边界测试。
- `RailwayAtlasCheck --llt-download OUTPUT.json`：真实公开包下载、完整转换与校验。
- `RailwayAtlas --ui-smoke FRESH_DIRECTORY --experiences-check --llt-fixture VERIFIED_JSON`：隔离个人存储的界面、地图播放、停站和更新失败保留测试。
- 上述应用命令加 `--llt-sync-check`：通过更新按钮所用对象实际联网同步，并验证完整落盘和上一版备份。最终安装版已通过。
