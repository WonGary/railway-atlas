# 0.8.17 阶段构建 2

网页「更多」中的车次盲盒、铁路侦探、站序拼图和每日时刻使用随包全国时刻快照。用桌面和手机窗口验证了从普通菜单出题、保存拼图 PNG、进入 Z230 的指定乘车区间以及跨日换题。匿名题图的 16 条轮廓来自连续轨道几何。

建设时光机按地区和日期在主地图绘制区段。逐点核对了六个地区共 4,358 条 OSM way、64,960 个原始顶点。桌面和手机回归覆盖开通、停运、施工、日期未知、区段来源和切换地区。退出后恢复原镜头和图层。

车次回归使用 2026-11-26 始发日历。[逐车计时](journeys.json)来自本机 HTTP 服务上的 Edge。每趟使用新的浏览器上下文，计时从选定车次到地图画出所有区间。随后单独打开明信片并导出实际乘车区间。12 个车号中，11 趟有排图，首次绘图最慢 172 毫秒，区间 PNG 最慢 193 毫秒。V6461 当日未收录。D174、V571、V604 全程分别画出 14、29、21 个连续区间。

D174 另测断网重开。桌面从车次搜索进入，手机从陇南站车次表进入。两端均在断网后重新加载并启动跟随。手动拖图后重新跟随，镜头距列车分别为 0、0.5 像素。手机图例按播放栏的实际高度避让关闭按钮。

网页单独打包可运行 `python3 Portable/package.py --web-only <新输出目录>`。本机 Apple 芯片版使用 `bash Scripts/build-macos.sh release`。这两项构建可随功能批次发布。Windows、Android 和 iOS 的最终构建在整组功能验收后执行。
