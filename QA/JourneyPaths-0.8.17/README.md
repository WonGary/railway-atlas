# 铁路漫游径路回归，0.8.17

按 2026 年 11 月 26 日的始发日历检查。D174 西宁至攀枝花南的 14 段、V571 北京丰台至厦门北的 29 段，以及 V604 运城至北京西的 21 段均可连续播放。D174 原缺陇南至广元。运行计划将这段记作兰渝兰渭段，沿途经过姚渡、羊木，计价里程为 139 公里。

## 路线库

基线为本机 0.8.16 路线库，已含上一轮 V604 修复。两次统计使用同一份 2026-11-24 全国时刻快照的 11,569 条排图、96,806 个停站区间。全程可用要求每个区间有轨迹，相邻两段在车站的端点相距不超过 120 米。

| 全库检查 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 全程连续的排图 | 9,552 | 9,991 |
| 部分区间可用的排图 | 1,792 | 1,361 |
| 整趟缺少轨迹的排图 | 225 | 217 |
| 缺轨迹的停站区间（按车次累计） | 6,110 | 4,978 |
| 已有轨迹之间的站内断点 | 213 | 120 |

743 个车次取得 1,132 段轨迹，其中 795 段从同径路的完整轨迹截取或复用，223 段由已核对的分段拼接，114 段经 OSM 轨道搜索取得。439 条排图由缺段转为全程连续。逐条对比保留了基线的所有已有区间和全程连续记录。余下的缺段按站对列在 [coverage.json](coverage.json)。

`Scripts/repair-route-atlas.py` 读取原路线分组、全国站表和 `Scripts/export-route-plans.cjs` 导出的运行计划。它核对排图指纹、经由线路、站所顺序及分段里程，在正向或反向轨迹中寻找可用区间。站内超过容差的衔接还需匹配到轨道。程序把新分组及索引写入单独目录，两个客户端使用同一套文件。
