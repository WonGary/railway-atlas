# 铁道漫游 0.7.0 · 网页与桌面便携版

手机和电脑都可以直接[打开铁道漫游](https://wongary.github.io/railway-atlas/)。iPhone 和 iPad 在 Safari 的分享菜单里选「添加到主屏幕」，Android 在 Chrome 菜单里选「安装应用」。两种方式都能从桌面图标进入。

Windows 可下载 `Windows-x64.zip` 或 `Windows-arm64.zip`。Mac 的 `macOS-universal.zip` 同时支持 Intel 和 Apple 芯片。解压整个文件夹，Windows 双击 `Railway-Atlas.exe`，Mac 双击「打开铁道漫游.command」。保持启动窗口打开，在浏览器里使用地图。Mac 便携启动器采用临时签名，Windows 便携包为未签名 EXE。`Web-PWA.zip` 供自行部署，四个 ZIP 的校验值见 `SHA256SUMS.txt`。

## 从哪里开始

- 「沿线旅行」可回放 G337 北京西至南昌西和 G6580 香港西九龙至肇庆东。选定上下车站就可只看其中一段。点播放条右侧的 × 即可退出，刷新后会记住。时刻对应各自的快照日期，列车位置按时刻估算。
- 在「线路 → 本机时刻库」选择路路通官方 APK，或导入原生版的 `lulutong.json`、`library.json`。选始发日期后，可查车次、本站排图和途经线路的完整站序，包括线路所。桌面便携版也可从路路通同步排图。网页读取 APK 时只用其中的资料文件。
- 在「图层」导入原生 `.railcache` 后，可用本机瓦片匹配其他车次的全部或部分径路。京九线大营镇至南宫东和京原线燕山至良各庄均已实测。瓦片缺换线点、轨道不连贯或里程对不上时，页面会指出具体区段。
- 在「图层」打开上海、南昌区域地图，也可导入自己的 `.railmap` 或 `.railcache`。全国低比例尺概览随包提供。六城地铁详情按需读取，含 318 条线路关系和 3,204 个站点对象，含分方向和站台记录。「发现城市与车站」可以定位 283 座城市和 42 处车站地标。
- 桌面便携版选站后，点「查看途经线路、线路所与本站车次 → 查询中国铁路地图站表」，可查看原站公开的更新日期和线路站序。GitHub Pages 提供导入库查询和原站链接。原站服务使用 HTTP，便携版仅向它发送所选站名或要素编号。
- 地图问答支持 GPT、Claude、DeepSeek、豆包和自定义接口。地址、模型和协议均可设置。Key 由使用者填写，在当前页面内存中保存。

## 数据与版本

向朋友分享网页即可使用随包快照。个人时刻库、地图缓存和护照通过本机文件导入。底图、新视野的在线轨道、原站查询和问答需要联网。桌面包和 Pages 的浏览器存储各自独立。

手机使用 PWA。Mac 和 Windows 便携版通过默认浏览器打开本机地图。需要 Apple 地图界面和原生轨道搜索时，使用 [macOS 原生版 v0.6.0](https://github.com/WonGary/railway-atlas/releases/tag/v0.6.0)。
