# 铁道漫游 0.8.1

放大到北京西站，Z16 可以看到站房轮廓，Z17 能分辨 10 个铁路站台。西直门在 Z18 还会显示已测绘的乘客通道。深色和浅色底图各有一套配色。呼家楼现有两条站台线，地图保留线形。

Mac 原生版、iOS、Android、Windows 便携版和网页共用同一份站区资料。北京、上海和香港部分站区的 90 个要素随包提供。在其他车站，可以打开「图层」，放大到 Z16 后点「补充当前站区」。取得的细节以后可以离线查看。紫色虚线表示有测绘记录的乘客步行通道，现场换乘请按站内指引。

Windows 用户按处理器选择 x64 或 arm64。Android 用户可以覆盖安装 APK。iPhone、iPad 用户可直接打开网页。发布者也可以用自己的 Apple 开发者团队给原生归档签名，发 TestFlight 邀请。
