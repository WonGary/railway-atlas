# 铁道漫游 0.8.1 网页地图

[打开地图](https://wongary.github.io/railway-atlas/) ｜ [下载安装包](https://github.com/WonGary/railway-atlas/releases/latest)

第一次打开是全国地图，随后会记住上次看过的位置。「图层」可按铁路速度、用途、状态、轨道网络或单条城市线路筛选。点线路或车站可看资料。「设置」可调地图模式、线宽、车站大小、底图亮度和面板布局，也可导入或导出地图设置。沿线旅行、时光机和铁路护照在「更多」里。

在「图层 → 数据来源与区域地图 → 地图底图」可以选择 OpenFreeMap 或 VersaTiles 矢量底图。两家服务都使用 OpenStreetMap 数据，铁路和车站可以在任一底图上点选。首次打开默认使用 OpenStreetMap 栅格底图，之后会记住你的选择。

放大地图，站名会直接显示在站点旁边。浅色底图用深灰字，深色底图和卫星影像用浅灰字。站点密集时优先显示换乘站和大站。地图外观默认跟随系统，也可以在「设置 → 地图绘制 → 地图外观」手动切换。

Z16 开始显示车站轮廓，Z17 显示站台，Z18 显示乘客通道。北京西站能看到站台面，呼家楼有两条站台线，西直门还有站内步行通道。随包资料覆盖北京、上海、香港的部分站区。在线模式可在「图层 → 地图与站点」点「补充当前站区」，查询范围限于眼前的地图。取得的要素会留在本机。通道依据 OSM 测绘，不同楼层可在俯视图中重叠。现场换乘请按站内指引行走。[图层资料和许可](data/station-layouts.json)

## 使用本机资料

| 资料 | 网页入口 | 用途 |
| --- | --- | --- |
| 路路通官方 APK、`library.json`、`lulutong.json` | 更多 → 沿线旅行 → 本机时刻库 | 选择始发日期，查经停时刻、计价里程和经由线路。网页仅读取 APK 里的排图资源。桌面包也可点「从路路通同步时刻库」 |
| 含 `stops` 的 JSON | 更多 → 沿线旅行 → 导入时刻/径路 | 可附相邻停站的 `legs` 轨道坐标。只有时刻时仍可查看经停表 |
| `.railmap` | 图层 → 打开自己的 .railmap 文件 | 查看区域线路、车站及其 OSM 属性。随包提供上海和南昌两份区域地图 |
| `.railcache` | 图层 → 导入原生 .railcache 瓦片库 | 浏览器在本机分块复制并只读查询；需要支持 OPFS 和 WebAssembly。磁盘需有足够空间存放副本 |
| 护照 JSON 或 CSV | 更多 → 护照 | 备份、迁移乘车记录 |

网页自带 G337 和 G6580 的时刻快照、全国铁路启动概览、1,082 条城市轨道概览记录，以及北京、香港、济南、澳门、青岛、东京的线路和站点详情。线路关系、站台和方向按 OSM 对象计数，详细数据截取于 2026-11-05。首次访问联网完成后，网页会缓存应用和概览；看过的城市详情和随包区域地图也可离线读取。在线底图和新视野的细节需要网络。

导入时刻库后，从「车站」按站名查排图、整条线路和线路所。桌面便携包还可查询中国铁路地图原站，表头显示原站班表日期。线上网页提供原站链接。

随包轨道按经由、站序和里程匹配。其他车次有经由资料时，可在「图层」导入原生 `.railcache`，回到「更多 → 沿线旅行」点「用本机瓦片匹配径路」。覆盖不足可以缩短乘车区间。缺换线点、轨道中断或里程不符时会显示原因，经停表仍可查。

「地图问答」支持 GPT、Claude、DeepSeek、豆包和自定义端点。按账号填写模型 ID、协议、地址和自己的 Key。Claude 可选服务端搜索和网页读取。浏览器直连需要端点允许跨域访问。回答可选中复制，也可复制原文或带格式的内容。Key 留在当前页面内存；勾选「记住地址和模型」会保存连接设置。

## 安装与预览

Windows 和 Mac 可解压便携版后启动，手机可将网页加到主屏幕。下载包根目录的《使用说明》给出了各平台的打开方式。本机预览只需运行：

```sh
python3 -m http.server 8080 --directory Web
```

随后访问 `http://127.0.0.1:8080/`。自行部署时把 `Web/` 的内容放到同一 HTTPS 路径，保留目录结构。重建桌面 ZIP 使用 `python3 Portable/package.py <新的输出目录>`，需要 macOS、Go 和 Command Line Tools。
