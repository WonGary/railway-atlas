# 铁道漫游 0.8.3

北京、济南、青岛、上海、深圳、广州增加了可离线查看的站区图形。点车站资料里的「查看站区细节」，即可放大到本站。北京育新有站体轮廓，广州沙河有地面站厅，北京呼家楼有两条站台线，广州磨碟沙可以看到实测的换乘通道图形。

左侧「图层 → 底图与站点 → 站区细节」有五个独立开关。Z16 可看车站轮廓，Z17 加入站厅和站台，Z18 显示乘客通道和已知站台号。在线地图会继续查询地图中心附近的资料，成功后保存在本机。

随包的 6,643 个要素中，独立标注的站厅只有 5 个。站台按已有的面、线或点显示。同一站内不同楼层的站台和通道在俯视图上可能重叠。[查看 OpenStreetMap 来源、日期和许可](data/station-layouts.json)
