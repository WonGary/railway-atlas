# 铁道漫游 0.8.5

放大到任意城市，地图先读取当前视野收录的地铁站区。Z14 起显示站体，Z15 加入站台和站厅，Z16 加入出入口和通道。原生版随包提供分区资料，网页版按需下载并缓存。

出入口保留实际编号，站台可显示为面、线或点，具体取决于当地的测绘记录。在线模式还能读取站区关系和更多室内步道。只有出口位置的车站会显示出口点，通向站台的走法需要单独的通道记录。

在巴黎 Vavin，3 号和 4 号出口相距约 7 米。两个圆标错开时，细线指回实际出口。新加坡另外收录陆路交通管理局的 613 个出口点，包括 Queenstown 的 A 至 D 口。
