# 铁道漫游 0.8.10

在地图上点线路，或在车站资料中展开途经线路，地图会突出选中的轨迹和已知站点。点击其他线路可以切换，点击「恢复全图」可以取消。全国线路资料按有地理轨迹的区间绘制，只有站点位置的线路显示站点。国铁概览图只标出选中的轨道区段。

铁路护照的乘车区间图和明信片按上下车站取景。实线表示乘车径路，浅色虚线是省界。大图标出途经省份及沿线附近的主要城市，跨海行程还能看到两岸的海岸线。短途图会标注区间内的经停站，小票面优先保留上下车站。网页护照可在每条记录下展开区间图，八种网页明信片均可导出为 1280 × 720 的 PNG。

省界、海岸线和城市点使用 [Natural Earth 5.1.2](https://github.com/nvkelso/natural-earth-vector/tree/v5.1.2/geojson) 的公开领域数据，经简化后随包提供。铁路轨迹使用[车次与径路资料](RELEASE_NOTES_0.8.9.md)，各自的署名与许可仍适用。
