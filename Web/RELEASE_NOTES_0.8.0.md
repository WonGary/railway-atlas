# 铁道漫游 0.8.0

**打开就是地图。** 第一次进入显示全国，以后回到上次浏览的位置。点铁路、地铁或车站看资料，收藏时可以填城市和标签。「图层」里可按速度、用途、状态、网络及单条城市线路筛选。在建铁路用黄色虚线，在建城市轨道用灰白虚线。沿线旅行收在「更多」里，退出后回到之前看的地方。

「设置」可调整线宽、站点大小、轨枕纹理、底图暗化及面板布局。网页和 Android 使用 WGS84，标准底图来自 OSM，卫星概览来自 NASA Blue Marble。原生 iOS 使用 Apple 地图，保留原生配置、坐标对齐、要素检视与缓存管理。地图问答可选多家服务、模型和输出长度，API Key 由使用者填写。

| 文件 | 打开方式 |
| --- | --- |
| `Android.apk`（文件名含版本号） | Android 8 及以上可安装。地图界面、铁路概览与六城详情随包提供 |
| `iOS-xcarchive.zip` | iPhone / iPad 原生真机归档。发布者使用自己的 Apple Developer Program 团队签名后，向朋友发送 TestFlight 邀请 |
| `Windows-x64.zip` / `Windows-arm64.zip` | 解压后双击 `Railway-Atlas.exe` |
| `macOS-universal.zip` | 解压后打开「打开铁道漫游.command」，支持 Apple 芯片和 Intel Mac |
| `Web-PWA.zip` | 自行部署，或直接使用公开网页 |
