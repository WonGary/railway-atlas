# 铁道漫游 0.8.8

点地图上的铁路车站，右栏会打开本站的线路和车次。展开线路可以从起点看到终点，逐站查里程和线路所。展开车次可以看全程到发时刻。大站每页显示 30 条，支持筛选和跳到末页。

随包全国时刻表含 11,569 条车次记录，线路表含 759 条线路。日期按本站当地的开行日历处理，跨日到发时刻会标出天数。全国时刻与线路表来自 Jeremy Gao 的 2026-11-24 中国铁路 GTFS 发布包，由 RailGo-Parser 等资料整理。车站坐标来源于 OpenStreetMap。本站转换了数据格式，保留了停站顺序和开行日历。[全国数据与许可](https://github.com/wensimehrp/chinese-railway-gtfs/releases/tag/gtfs-20261124-112841) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

北京西、石家庄、杜家坎所和盐步所另附中国铁路地图快照。线路图保留原站站序、里程和说明。车次表保留原站更新月份。原站未公布客运班表的线路所仍可查所属线路。快照由铁道漫游从原站提取并转换，按原站的署名－相同方式共享 4.0 许可提供。[中国铁路地图 · Kejing Peng](http://cnrail.geogv.org/zhcn/about) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

有路路通时刻库时，可查经过本站但不停靠的列车，以及分段经由和沿途站所。通过时刻未公布时，表中显示「通过」。跨夜区间无法确定通过日期时，会标出这项限制。
