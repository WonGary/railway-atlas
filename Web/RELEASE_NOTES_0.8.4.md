# 铁道漫游 0.8.4

选中车站，点「查看站区细节」。车站轮廓从 Z14 开始显示，站厅和站台从 Z15 开始显示。到 Z16，地图会加上出入口、乘客通道和已知站台号。

蓝圈里的 C1、C2 是地铁出口号。青岛站的「东进」「西进」分别指东进站口和西进站口。紫圈里的「换」表示换乘通道，「→B2」表示该段步道连到 B2 口。位置有记录、编号未知的出入口显示为小圆点。标记聚在一起时，继续放大可分辨更多编号。

左侧「图层 → 底图与站点 → 站区细节」新增「出入口与方向」和「通道标识」两个开关。随包收录 6,008 个出入口和 971 条有标识的通道，站厅和通道的收录情况因站而异。[OpenStreetMap 资料与许可](data/station-layouts.json)
